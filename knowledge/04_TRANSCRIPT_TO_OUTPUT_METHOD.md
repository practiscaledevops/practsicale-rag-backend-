# Copywriting Rules

## Before writing

Determine:
- audience
- offer
- funnel stage
- desired action
- strongest proof
- biggest skepticism
- one core idea

If those are unclear and materially affect the copy, ask.

## Hooks

A hook earns the next sentence.

Strong hook sources:
- surprising specific number
- sharp contrast
- recognizable problem
- counterintuitive belief
- consequence
- real story
- direct challenge
- unanswered question

Avoid empty hooks such as:
"You won't believe this."
"This changes everything."
"Attention healthcare owners!"

## Body

Each paragraph should do one job.

Possible jobs:
- deepen the problem
- explain why it happens
- reveal mechanism
- give proof
- handle skepticism
- create contrast
- show consequence
- move toward action

Delete paragraphs that only repeat the headline.

## CTAs

The CTA should be proportionate.

Cold educational post:
comment, follow, DM, or learn more.

Direct-response ad:
clear next action.

Sales follow-up:
specific commitment.

Do not add a CTA just because "marketing copy needs a CTA."

## Claims

Never invent:
- revenue
- client count
- team size
- testimonials
- paychecks
- conversion rates
- partner counts
- patient results
- timelines
- guarantees
- scarcity
- credentials

If a supplied number is old or likely to change, either confirm it or date/contextualize it.

## Formatting

Prefer:
- short paragraphs
- readable spacing
- occasional bullets when genuinely useful
- strong first line

Avoid:
- em dashes
- en dashes
- decorative punctuation
- constant ALL CAPS
- five emojis per paragraph
- every sentence on a separate line unless the platform/style calls for it

## Banned / heavily discouraged marketing words

Unless quoted or genuinely necessary:
- guaranteed
- secret
- transform
- unlock
- explode
- effortless
- revolutionary
- game-changing
- cutting-edge
- robust
- seamless

## Quality-control questions

Before submitting:

1. Is the first sentence worth reading?
2. Is there one clear idea?
3. Could a competitor say the same thing?
4. Did we explain the mechanism?
5. Did we use the strongest available proof?
6. Did we overclaim?
7. Is the reader's skepticism answered?
8. Does it sound spoken?
9. Can 20 percent be deleted without losing meaning?
10. Would Afra actually say/post/send this?
