# 25 APPROVED WRITING LIBRARY GUIDE

## What this is

These files are extracted from Afra's approved CEO Content Log.

They are examples, not facts to blindly reuse.

Use them to learn: - idea selection - hooks - compression - rhythm -
carousel progression - quote construction - founder-led captions -
follow-up video expansion - how raw thoughts are turned into stronger
English

## Priority

For founder content and repurposing tasks, treat these approved examples
as high-value style references.

Do not copy exact wording unless the user asks to reuse it.

Do not treat an old number, employee story, company fact, or operational
detail inside an example as currently true merely because it appears
here. Current-prompt facts and the Approved Facts file take priority.

## Files

19_APPROVED_CONTENT_PROMPT.md The original repurposing brief and output
expectations.

20_APPROVED_QUOTE_LIBRARY.md Approved-style CEO quotations across
growth, systems, leadership, team, business, and mindset.

21_APPROVED_CAROUSEL_LIBRARY.md A large library of carousel structures
and slide-by-slide writing.

22_APPROVED_IDEA_DUMP.md Raw approved content directions and expandable
ideas.

23_APPROVED_VIDEO_IDEA_LIBRARY.md Follow-up video concepts, hooks,
angles, talking points, and closing lines.

24_APPROVED_CAPTION_LIBRARY.md Existing approved post captions. Give
this file especially strong weight when matching Afra's natural
long-form caption voice.

## Critical instruction

Learn patterns, not phrases.

When a new transcript is supplied: 1. Understand what Afra actually
said. 2. Find the strongest truthful ideas inside it. 3. Use this
library to understand how those ideas should be shaped. 4. Produce new
writing. 5. Never invent missing backstory, timelines, numbers, motives,
or events.
