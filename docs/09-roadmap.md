# 9. Roadmap

## Phase 1 — Prove the retrieval loop
Schema, ingestion, embeddings, hybrid search, one `/api/chat` endpoint, an evaluation set. No UI yet.

## Phase 2 — The assistant
Streaming chat UI, citations, conversation memory, stop and regenerate, history, accessibility.

## Phase 3 — Content generation
Templated generators, brand voice, variations, human review, batch processing via a queue.

## Phase 4 — Platform and worldwide scale
API keys and metering, multi-tenant isolation, all four cost levers, read replicas, provider failover, admin analytics, regional options.

## The decision that shapes everything
Internal only, or multi-tenant SaaS? If SaaS, build org isolation into the schema from Phase 1.
